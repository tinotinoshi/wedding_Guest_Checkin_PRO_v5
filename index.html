📨 Messaging ya moja kwa moja

Kwa kutuma picha ya invitation + QR kisha text kwenye WhatsApp, na SMS ya kawaida bila kufungua app ya SMS, mfumo huu hutumia Supabase Edge Functions. API secrets zikae kwenye Supabase server, si kwenye index.html.

WhatsApp API

Setup ya database (mara moja tu)

Kwenye Supabase → SQL Editor, tengeneza query mpya na u-run SQL ya database pamoja na supabase_messaging_setup.sql. Kisha deploy Edge Functions zilizopo kwenye ZIP.
